# ShiftForge

ShiftForge is an original automotive visualization web app inspired by the workflow category represented by MODS Nation.

## What works

- Realtime Three.js car configurator with three original vehicle presets
- Paint, finish, wheel, diameter, stance, aero and scene controls
- Orbit/zoom interaction and local build history
- Optional Puter sign-in and KV cloud build sync
- Real image-to-image AI concept rendering through Puter and GPT Image
- Seeded marketplace and community pages
- SEO comparison hub plus six static comparison pages
- Product, FAQPage and BreadcrumbList structured data
- Sitemap, robots and canonical metadata
- Responsive static export for GitHub Pages

## Local development

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run lint
npm run build
```

The app is a visual concept tool, not a wheel-fitment, engineering, safety or legal validation system.
